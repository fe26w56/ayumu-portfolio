# 由来と公開版の変更範囲

2026年10月28日に、運用版`health-tracker`の`web/`と`shared/`から切り出しました。
取り出した時点のGitツリーは`afd44f93c7c81bab678b0a88e472c97400bcf4c4`です。
`web/`は、同日に統合された旧`meal-planner`のフロントエンドです。
元のコミット履歴は、この公開リポジトリには引き継いでいません。

## 引き継いだもの

Today、Meals、Move、Bodyの画面、週間グラフ、食事の予定・実績の集計、運動候補のモデル、コンディション球体の描画を引き継ぎました。
共有モデルとフロントエンドの再エクスポートという配置も維持しています。
画面ごとの設計判断はREADMEから確認できます。

端末フレーム、キーボード、スクロール、カルーセルなどのモバイルランタイムは、既存のテンプレートを利用した部分です。
これらを独自にゼロから実装した成果とは扱っていません。
`mobile-runtime.lock.json`と検証スクリプトも引き継ぎ、保護対象26ファイルの内容を変更していないことを確認します。

## 公開用に変えたもの

| 対象 | 変更 |
| --- | --- |
| 食事・健康・運動のデータ | 公開デモ用の架空データを新しく作成 |
| レシピと運動パターン | 架空の少数の例に置換。個人の目標や重量を持ち込まない |
| 保存 | 検証付きのメモリ内ストアに置換 |
| 日付 | 2030年4月11日11時をデモの基準に固定 |
| 同期・認証 | 接続コード、PIN画面、端末トークン、復旧・バックアップ機能を削除 |
| 設定 | デモの説明、リセット、表示テーマに限定 |
| フォント | 外部フォントへのアクセスを削除 |
| 食事集計 | 元の関数を単独ファイルへ移し、境界条件をテスト |
| 品質確認 | 公開範囲の検査、操作テスト、CIを追加 |

健診データ、ウェアラブルの取得処理、サーバー実装、運用資料、認証情報は含めていません。
健診タブはデータなしの表示です。
元のモデルに残るプロバイダー名は型や分類の定義であり、公開版からそのサービスにアクセスすることはありません。

元ファイルのGit blobハッシュは[source-manifest.json](source-manifest.json)に記録しています。
この一覧は抽出元との対応を示すもので、公開後のファイルがすべて元の内容のままであるという意味ではありません。
