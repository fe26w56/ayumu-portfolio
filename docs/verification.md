# 検証の条件と限界

2026年10月28日、Node.js 24で検証しました。

| 確認対象 | 方法 |
| --- | --- |
| 公開範囲 | アプリのソースに外部URL、ネットワークAPI、運用版キャッシュのキーがないことを静的検査 |
| ランタイム | 引き継いだ26ファイルのハッシュを元のロックと照合 |
| 型と配布用ビルド | TypeScriptとViteによるビルド |
| 集計・保存 | 3件のモデルテスト。実績の優先、スキップの扱い、入力検証、コピーの分離とリセット |
| 操作 | 2件の画面テスト。記録、量の修正、リセット、4画面の移動、ダーク表示、データ不足表示 |
| データの分離 | テスト用の運用版キャッシュを置いても、デモが読み込まず変更もしないことを確認 |
| 通信 | 記録・編集・リセット中に、ローカルの配布ファイル以外へのリクエストがないことを確認 |
| 表示 | 390×844のスマートフォン幅と、1280×1000の端末プレビュー |

画面テストはPlaywrightとChromiumを使います。
ローカルの検証環境では通常のブラウザ配布ファイルを取得できなかったため、npmで配布されているChromiumとソフトウェア描画を使いました。
CIではPlaywrightの通常のChromiumをインストールして実行します。
スクリーンショットは架空データを表示したローカルの配布用ビルドから撮影しています。

## まだ示せていないこと

実機のiOS Safariやウェアラブル接続、本番APIの同期は、このリポジトリでは検証していません。
健康改善の効果や、運動候補の医学的な妥当性を検証するデモでもありません。
個人向けの目標や候補として使うことは想定していません。

現時点では、Three.jsを含む初回のJavaScriptが約1.28MB、gzip後で約358KBあります。
Viteからもチャンクサイズの警告が出るため、初期表示に必要な部分と、詳細表示で使う部分の分割が今後の課題です。
画面をまとめている`Prototype.tsx`も大きく、機能ごとの整理は引き続き必要です。
